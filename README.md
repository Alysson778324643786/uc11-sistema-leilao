# Sistema de Cadastro de Produtos (Leilão)

Projeto desenvolvido para a atividade prática, utilizando estruturação de sistema desktop, banco de dados MySQL e controle de versão com Git.

## Descrição do Projeto
Sistema desenvolvido para gerenciar dados de operações e cadastros, integrando conceitos de banco de dados e versionamento de código.

## Tecnologias Utilizadas
* Java (NetBeans)
* MySQL Workbench
* Git e GitHub
